# 材质真实感校准记录

> 日期：2026-10-11
> 范围：依设计文档 §6.4.4 基准，对 7 个纹理族（crystalClear / agate / tigerEye / woodGrain / amberSwirl / pearlNacre / metalBrushed）逐条校准 `RenderSpec` 并改进绘制手法。

## 一、绘制手法升级（`src/engine/bead-painters.ts`）

| 纹理族 | 改动 |
| --- | --- |
| 通体 | 主体径向渐变按 `translucency` 整体提亮、暗部向底色收敛；新增「通透材质内部亮核」（`translucency>0.3` 时体内透出高光，模拟光穿球） |
| crystalClear | 折射亮弧 + 底部聚光焦散 + 边缘折射亮环，通透玻璃感更真 |
| agate | 同心带改为「有机摆动缠丝」（正弦扰动 + 偏心），告别完美椭圆，更接近玛瑙絮状/缠丝 |
| woodGrain | 年轮 + 贯通木纹 + 「鬼脸节疤」（随机暗椭圆），强化木质辨识度 |
| metalBrushed | 镜面多段渐变 + 拉丝 + 「各向异性高光条」（竖直亮带），金/银靠 envLightColor 冷暖区分 |
| pearlNacre | 随机斑点 → 结构化「定向 orient 虹彩晕」（沿球弧的多色环 + 柔和高光晕），珍珠晕彩更可信 |
| amberSwirl | 流纹 + 气泡 + 边缘暖光透射（`lighter` 叠暖色环），蜜蜡通透感提升 |
| tigerEye | 贯穿猫眼亮带保留，亮度微提，方向稳定 |
