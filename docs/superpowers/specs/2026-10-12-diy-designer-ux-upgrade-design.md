# DIY 串珠设计器体验升级（P7）设计文档

> 日期：2026-10-12　状态：已确认（含打结与配饰交互逻辑补充）
> 背景：对标「珠了个珠」小程序设计器 + 用户新增硬需求，在 P6 交付的设计器基础上做体验升级。
> 前置约束：仍走 vshop uni-app 主线 pkg-diy 分包；后端 diy-plugin shop-api 零改动；@diy/calc 纯函数不动；金额分/毫米口径不变；i18n 五语言同步。

## 1. 目标与非目标

**目标**
1. 方案 C 双层融合：默认「直觉流」画布（点卡即上珠），轻量 chips 一键切专业模式（定手围/定颗数/混搭），两层共享同一序列数据。
2. 画布交互：珠子/隔片**拖拽换位**、**拖出删除**、点选快删；序列条与环上状态双向同步。
3. **预览全貌修复**：任意颗数/规格下整串手环完整可见（当前固定比例会裁切）。
4. 选料面板重构：分类侧栏 + 3 列素材网格卡 + 珠子/配饰双 tab + 搜索框 + 选中 ×n 角标 + 长按看素材详情。
5. 打结与配饰完整交互设计（§5）。
6. 独立引导页（§6）：右上角 ? 进入，首次进入自动引导一次。
7. 运营氛围：顶部实时胶囊（手围约/内孔周长 + 状态词 + 价格）、操作行（清空/暂存/推荐/完成设计）、画布品牌水印。

**非目标（本期不做）**
- 语音讲解/音效（YAGNI）
- 广场/详情/下单链路改动（P6 已交付，不动）
- 后端任何接口/字段变更
- 素材 admin 后台改造

## 2. 信息架构（方案 C）

```
designer.vue
├── 顶部胶囊条（常驻）：[手围约 X cm · 状态词] [¥价格] [帮助?]
│     └─ 专业模式下为 [内孔周长 X cm · 状态词]，点击开计算明细抽屉
├── 模式 chips：直觉流(默认) | 定手围 | 定颗数 | 混搭
│     └─ 原「自由拖拽」并入直觉流；chips 即 P6 四模式入口的重组
├── 画布区（BeadRing v2）
│     ├─ 全貌自适应缩放（§4.3）
│     ├─ 珠子拖拽换位 / 拖出删除（§4.2）
│     ├─ 结位与配饰挂位渲染 + 配饰拖拽（§5）
│     └─ 中心品牌水印（低透明度，取全局配置，取不到显示纯圆环）
├── 操作行：清空 | 暂存 | ↻推荐 | 完成设计（保存方案→服务端复算报价）
└── 选料面板（MaterialPanel v2，§4）
guide.vue（新增独立引导页，§6）
```

**模式映射（对 useDesigner 的改动）**
- 新增 `mode: 'intuitive'`（默认）。直觉流 = free 模式超集：序列数据结构完全复用 `sequence`（string[]），追加=push 尾部；若 P6 序列含对称镜像逻辑则原样保留并加开关（默认沿用现状），无则不新增。
- `byWrist / byCount / pattern` 三个专业模式逻辑不变；从直觉流切入时以当前 sequence 反推槽位/数量配置，切回时按当前配置展开成序列。
- 状态词由 calc v2 输出的内孔周长与目标手围差值计算：`过短(<−20mm) / 偏短(−20~−4) / 合适(−4~+4) / 偏长(+4~+20) / 过长(>+20)`（阈值随松紧档联动，以 easeOf 档位值 4/10/20 为基准）。
- **混径实时收敛（已有能力，显性化）**：calc v2 序列模式逐颗求和——中心线周长 = Σ每颗直径，内孔周长 = 中心线周长 − 加权平均珠径修正；每点一颗立即重算并更新状态词；引导页用 6×7mm+6×8mm+6×9mm 为例图解该算法。

## 3. 选料面板重构（MaterialPanel v2）

- **结构**：`珠子 | 配饰` 双 tab + 搜索框（名称/别名模糊，显示计数）+ 左侧分类竖滑栏（diyCategories，当前类高亮）+ 右侧 3 列素材网格卡。
- **素材卡**：圆珠缩略图（renderUrl→preset→纯色三级回退，复用 bead-render）+ 名称 + `规格 ¥价格`（多规格点卡先弹规格行）；选中态 border brand + ×n 角标。
- **长按详情**：长按 350ms 弹素材详情半屏弹层（大图 + 介绍 + 全规格价格列表 + 「选它」）；H5 长按计时器，mp 端 longpress。
- **性能**：网格分页加载（每类首屏 20 个），图懒加载。

## 4. 画布交互与全貌修复

### 4.1 直觉流上珠
- 点素材卡按选中规格追加到序列尾部，画布立即渲染（120ms 落位动画，reduced-motion 跳过）。
- 配饰 tab：吊坠/流苏等 decor 项，点击挂到默认挂位（§5），不进几何。

### 4.2 珠子拖拽换位与删除
- **命中**：touchstart 触点转极坐标，取角距最近且半径差 < 珠半径的珠。
- **换位**：ghost 珠跟手，原位半透明；落点角度到相邻两珠之间即插入该索引（splice+insert）；松紧/价格实时重算。
- **删除**：拖出环心距 > 1.6×环半径显示红 ✕ 吸附态，松手删除；位移阈值 6px 内视为点选（弹迷你气泡：删除/换规格）。
- **镜像联动**：若存在对称镜像逻辑则拖拽/删除联动（气泡提示），可关闭。
- 序列条（SequenceStrip）与环上拖拽共用同一 sequence，双向同步。

### 4.3 全貌自适应缩放（修复要点）
- 现状问题：BeadRing 固定比例绘制，颗数多/珠径大时环被裁切。
- 修复：`centerR = calc v2 收敛环中心线半径；outerR = centerR + max(珠半径) + decor 最大外伸；scale = clamp((min(canvasW,canvasH)/2 − padding12)/outerR, 0.4, 1.15)`；160ms 过渡。
- 画布高度 = min(62vh, 420px)；>768px 居中限宽 480px。
- 验收：12mm×20 颗、8mm 混 12mm×28 颗、含吊坠外伸三种极限 case 整环完整可见且留白 ≥12px。

## 5. 打结与配饰交互逻辑（本期新增重点）

### 5.1 结位（打结点）
- **位置**：固定 12 点位（画布正上方），不随珠子拖拽移动、不占序列槽位。
- **渲染**：结点小圆 + 两条短线尾（弹力线打结示意），低透明度线色；参与 outerR 计算（线尾外伸计入），保证不被裁切。
- **属性**：不计颗数、不计价（成本体现在配线）；「配线」明细行沿用 P6：`弹力线长度 = 内孔周长 + 160mm 打结留量`。
- **显隐**：画布设置入口（长按画布空白处或胶囊条齿轮位）可切换「显示/隐藏结位标记」，默认显示；隐藏仅影响渲染，不影响计算。
- **流苏默认挂结位**：见 5.3。

### 5.2 配饰分类与数据语义
| 类型 | 进序列？ | 进几何？ | 计价 | 示例 |
|---|---|---|---|---|
| 金属隔珠/定位珠/金珠 | ✅ 按「珠」进 sequence | ✅ 参与收敛 | ✅ | 隔珠、转运珠 |
| 吊坠类 decor | ❌ 挂位记录 | ❌（外伸计 outerR） | ✅ | 玉坠、平安扣 |
| 流苏类 decor | ❌ 挂位记录 | ❌（外伸计 outerR） | ✅ | 流苏、铃铛 |

- decor 挂位数据模型：`decors: [{ id, slot: number }]`，`slot` = 所在间隙索引（第 k 与 k+1 颗珠之间，k 从 0 起；空串时忽略）。
- 吊坠/流苏**只计价不进几何**（沿用 P6 语义），新增的是**挂位可视化与拖拽**。

### 5.3 配饰挂位交互
- **默认挂位**：吊坠 → 6 点位（结位正对面，slot = 序列中点对应间隙）；流苏 → 结位处（12 点位，专用 knot slot）。序列为空时挂位记为 pending，上珠后自动吸附。
- **拖拽**：decor 可拖——拖动中 ghost 跟手，落点吸附到最近的珠间隙（角度最近两珠之间的中点）；流苏可拖离结位到任意间隙，也可拖回结位（靠近 12 点位阈值内自动吸附 knot slot）。
- **点选**：点 decor 弹迷你气泡（删除 / 换成同类其他规格）。
- **多 decor**：同类多个时均匀分布为默认（拖拽后以手动位置为准）；上限=间隙数。
- **镜像联动**：decor 不参与镜像联动（挂位是单点语义）。
- **与珠子拖拽共存**：decor 拖拽优先命中（decor 渲染在珠层之上，命中检测先查 decor 挂点再查珠）；空隙拖拽不误触珠子（命中半径 decor 18px > 珠半径判定先行）。
- **删除**：拖出画布（同珠子 1.6× 阈值）删除 decor；进序列类（隔珠）删除走珠子逻辑（§4.2）。

### 5.4 配线与明细
- 计算明细抽屉「配线」行增加打结说明文案：「含 160mm 打结留量」；结位隐藏不影响该行。
- decor 价格并入「配饰」小计行（P6 已有），明细新增挂位提示不新增计算字段。

## 6. 独立引导页（guide.vue，新增）

- **入口**：右上角 ? 常驻；首次进 designer 自动跳转一次（storage 标记 `diy_guide_seen`，可跳过）。
- **路由**：`/pkg-diy/pages/guide`，分包内新增页面。
- **内容大纲（详细版，i18n 五语言）**：
  1. 三步上手：点卡上珠 → 拖拽调整（换位/拖出删除）→ 完成设计
  2. 直觉流 vs 三个专业模式：各自适用场景图解（定手围=给礼物、定颗数=照样子复刻、混搭=进阶搭配）
  3. 手围测量方法图解：四指并拢最宽处软尺绕量 / 拿现有手串量内径对照
  4. 松紧度怎么看：状态词含义表（过短~过长）+ 三档松紧（贴合 4 / 舒适 10 / 宽松 20mm）说明
  5. 混搭直径自动收敛图解：以 6×7mm+6×8mm+6×9mm 为例演示逐颗求和 → 内孔周长 → 松紧判定
  6. 打结与配饰：结位示意、吊坠/流苏默认挂位与拖拽方法、金属隔珠按珠计价、160mm 打结留量说明

- **形态**：竖滑长页（图解用静态 SVG/预设图），底部固定「开始设计」按钮返回 designer（uni.navigateBack 或 redirect）。

## 7. 运营氛围

- **推荐 ↻**：按当前目标手围规则化生成搭配（主珠按分类热度 + 隔片互补/径 + seeded 随机可复现），填充直觉流序列；纯前端。
- **暂存**：未登录本地草稿（storage 单份），登录后保存走 P6 createDiyPlan；「完成设计」= 保存+复算报价。
- **清空**：二次确认。
- **水印**：画布中心低透明度品牌字/圆环（ShopGlobalConfig 店铺名），不遮挡交互。

## 8. 数据模型与状态

- `useDesigner` 扩展：`mode` 加 `'intuitive'`；`sequence` 唯一真源；新增 `capsule`（状态词+目标手围）、`recommendSeed`、`decors: [{id, slot}]`、`knotVisible`。
- 序列操作 API 收敛：`appendBead(materialId, specId) / moveBead(from,to) / removeAt(i) / replaceAt(i,specId) / applyRecommend(seed) / moveDecor(id,slot) / removeDecor(id)`。
- 兼容：URL 带 planId 仍走 P6 详情/复刻链路；草稿恢复进直觉流；保存方案时 decors 随 plan 现有 decor 字段持久化（沿用 P6 字段，slot 为前端展示层状态，不新增后端字段）。

## 10. 边界与降级

- decor 参与 outerR 但不参与珠子换位逻辑；空序列时 decor pending 不渲染挂点。
- 单珠序列不允许珠换位（无可交换位置）；空序列画布显示引导态。
- mp-weixin：touch 事件与 canvas 2d 同套逻辑；movable-area 仅用于序列条。
- 拖动中仅重绘 ghost 层，落位全量重绘（旧机型帧率）。
- 结位/水印在低端机关闭动画仅保留静态渲染。

## 11. 验收标准

1. 手机视口（390×844 dpr=2）截图：直觉流空态/12 颗/20 颗/含吊坠+结位，整环全貌可见。
2. 珠子拖拽换位、拖出删除、点选删除、镜像联动（若有）可用；decor 拖拽换隙、拖回结位、拖出删除可用。
3. 吊坠默认 6 点位、流苏默认结位；多 decor 均匀分布；与珠拖拽命中不冲突。
4. 直觉流 ⇄ 专业模式往返，序列/价格/明细一致；6×7+6×8+6×9 混径实时松紧反馈正确。
5. 引导页 7 节内容完整（五语言），首次自动引导一次、? 随时进、底部返回。
6. 搜索、分类侧栏、长按详情、×n 角标、推荐、暂存、清空可用。
7. P6 手工用例 16 条回归（用例 3/4/5/6/7 更新为直觉流路径）+ 新增打结/配饰用例。
