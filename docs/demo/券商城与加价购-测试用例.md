## 1. 文档说明

本文档为 M2 券商城（领券 / 购券 / 积分 / 兑换码 / 卡包）与商品页加价购的**手工回归用例**。

优先级：P0 = 主链路（必须通过）；P1 = 关键分支；P2 = 次要项。

### 1.1 环境依赖（联调前提）

| 依赖项 | 说明 |
|--------|------|
| game 后端（coupon-plugin） | 需已部署且含券商城/加价购 resolver（`couponSaleCatalogue`、`createCouponSaleOrder`、`attachCouponToOrder` 等） |
| 管理后台已配券 | 领券中心券（salePrice=0）、可售券（salePrice>0、渠道含 SALE）、券包、积分兑换券、兑换码券模板各至少 1 条 |
| 测试账号 | 已注册客户，余额充足（建议 ≥ 券价），积分数已知 |
| 微信支付 | 小程序 JSAPI 需真实微信环境；H5 用微信外浏览器走 H5 支付 |

> 2026-10-03 本地静态验收记录：后端未启动时 5 Tab 空态/登录提示渲染正常、无 JS 报错（截图为证）。以下用例需在有后端的环境执行。

## 2. 领券 Tab（TC-CL）

### TC-CL-1　正常领取　【P0】
- **前置**：领券中心有可领券（claimable、未超总量、未达每人限领）。
- **步骤**：进入券商城 → 领券 Tab → 点击「立即领取」。
- **预期**：toast「领取成功」；进度条已领数 +1；卡包「未使用」出现该券。

### TC-CL-2　每人限领　【P1】
- **前置**：券 perUserLimit=N，当前用户已领 N 张。
- **预期**：按钮显示「已领取」且置灰，点击无效。

### TC-CL-3　总量抢完　【P1】
- **前置**：claimedCount ≥ totalCount。
- **预期**：按钮显示「已抢完」且置灰。

### TC-CL-4　进度条展示　【P2】
- **预期**：totalCount>0 的券显示进度条与「已领 x/y」，宽度按百分比；totalCount=0 不显示。

---

## 3. 购券 Tab（TC-SL）

### TC-SL-1　场景切换加载　【P0】
- **步骤**：购券 Tab → 切「线上专用」→ 切「到店可用」。
- **预期**：列表按场景重新拉取（couponSaleCatalogue scene 参数），仅含对应渠道可售券/券包。

### TC-SL-2　余额支付购单券　【P0】
- **步骤**：点单券「买 ¥xx」→ 弹层选「余额支付」→ 点「¥xx 支付」。
- **预期**：toast「支付成功」→ 自动跳「卡包/未使用」→ 券在列表；余额明细出现扣款。

### TC-SL-3　微信支付购单券（小程序）　【P0】
- **步骤**：小程序内点「买 ¥xx」→ 选微信支付 → 确认 → 完成微信支付。
- **预期**：拉起微信收银台；支付完成后前端轮询确认 PAID → 跳卡包；券在列表。

### TC-SL-4　微信 H5 支付　【P1】
- **步骤**：H5（微信外浏览器）走微信支付。
- **预期**：跳转 payUrl 收银台；支付回跳后券到账（轮询兜底）。

### TC-SL-5　关闭弹层取消订单　【P1】
- **步骤**：下单进弹层后点「取消」/遮罩。
- **预期**：弹层关闭；后台出售单置 CANCELLED（不残留 PENDING）；余额未扣。

### TC-SL-6　券包购买　【P1】
- **前置**：有启用券包（salePrice>0）。
- **预期**：卡显示「N 类M张」与「合计可省」（仅当 Σ面额×张数 > 售价 时显示）；购买成功后包内每张券入卡包。

### TC-SL-7　未登录购券　【P2】
- **预期**：显示「登录后可购买优惠券」引导条；点击跳登录。

## 4. 积分 Tab（TC-PT）

### TC-PT-1　积分兑换成功　【P0】
- **前置**：积分充足，存在可兑换券。
- **预期**：toast 成功 → 跳卡包；积分扣减对应 spentPoints。

### TC-PT-2　积分不足　【P1】
- **预期**：toast「积分不足」，不发券。

### TC-PT-3　未开通积分服务　【P2】
- **预期**：toast「积分功能暂不可用」。

## 5. 兑换码 Tab（TC-RD）

### TC-RD-1　有效兑换码　【P0】
- **步骤**：输入有效 claimCode → 兑换。
- **预期**：toast 成功 → 跳「卡包/未使用」，券入包。

### TC-RD-2　无效/他店兑换码　【P1】
- **预期**：分别提示「兑换码无效」「该兑换码在当前店铺不可用」。

### TC-RD-3　空码禁点　【P2】
- **预期**：输入为空时兑换按钮 disabled。

---

## 6. 卡包 Tab（TC-WL）

### TC-WL-1　状态筛选　【P0】
- **预期**：未使用/已使用/已过期/已退回 四 tab 各自过滤正确；空态文案区分。

### TC-WL-2　场景子筛　【P0】
- **预期**：全部/线上专用/到店可用 过滤正确（ALL 券在两个场景筛下都可见）。

### TC-WL-3　临期排序与角标　【P1】
- **前置**：未使用含一张 7 天内到期券与一张长期券。
- **预期**：临期券排前且显示红色「剩 N 天」角标。

### TC-WL-4　出示券码　【P0】
- **步骤**：到店券（IN_STORE/ALL）点「出示券码」。
- **预期**：跳券码页，二维码与券码正确；线上专用券无此按钮。

## 7. 商品页加价购（TC-AT）

### TC-AT-1　加购成功　【P0】
- **前置**：商品绑定 SALE 渠道在售券（salePrice>0，非纯到店）；购物车有该商品的活动订单。
- **步骤**：商品详情页 → 「+¥9.9元 立即换购」。
- **预期**：toast「已加入订单，随单结算」；按钮变绿色「已换购 · 点击移除」。

### TC-AT-2　结算含券价　【P0】
- **步骤**：加购后去结算。
- **预期**：订单金额 = 商品 + 券价（surcharge line）；支付完成券入卡包。

### TC-AT-3　移除加购　【P0】
- **步骤**：已换购态点「点击移除」。
- **预期**：toast「已移除加价购券」；结算金额恢复，无券价。

### TC-AT-4　无活动订单引导　【P1】
- **前置**：购物车为空。
- **预期**：toast「请先将商品加入购物车」。

### TC-AT-5　纯到店券不展示　【P1】
- **预期**：usageScene=IN_STORE 的券不出现在加价购区块。

### TC-AT-6　未登录点击换购　【P2】
- **预期**：跳转登录页（redirect 回商品详情）。

### TC-AT-7　重复加购防护　【P2】
- **预期**：已加购的券按钮为移除态，不会重复 attach（后端幂等提示「该券已加购」）。
