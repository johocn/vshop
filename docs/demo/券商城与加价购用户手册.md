# 券商城与商品页加价购 —— 用户操作手册

> 配套文档：[《券商城与加价购-测试用例》](./券商城与加价购-测试用例.md)
> 应用入口：C 端商城（vshop，H5 / 微信小程序）
> 代码版本：vshop `67e5c47`（feat(coupon): 券商城 5 Tab 页 + 微信/余额支付 + 商品页加价购）

---

## 1. 功能入口

| 入口 | 路径 |
|------|------|
| 优惠券页顶部橙色入口条「券商城 · 购券/积分兑换/兑换码」 | 我的 → 优惠券 → 顶部横幅 |
| 会员中心快捷菜单「券商城」 | 我的 → 会员中心 → 券商城 |

页面地址：`/pkg-promotion/pages/coupon-mall`，共 5 个 Tab：**领券 / 购券 / 积分 / 兑换 / 卡包**。

---

## 2. 领券 Tab

1. 浏览可领优惠券列表：左侧橙色面额块（立减金额 / 折扣 / 免邮），右侧展示名称、门槛、有效期、使用场景标签（线上专用 / 到店可用 / 通用）。
2. 券下方有限量进度条（已领 x/y）。
3. 点击「立即领取」，成功提示后自动入卡包。
4. 特殊状态：
   - 「已抢完」：总量领完，按钮置灰。
   - 「已领取」：达到每人限领次数，按钮置灰。

## 3. 购券 Tab（券商城）

1. 顶部场景切换：**线上专用 / 到店可用**。
2. 券包大卡：显示「N 类 M 张」「合计可省 ¥xx」，点击「立即购买」。
3. 单券卡：点击「买 ¥xx」。
4. 弹出支付方式（确认支付弹层）：
   - **微信支付**（推荐）：小程序内拉起微信支付；H5 跳转微信支付页。
   - **余额支付**：账户余额充足时可直接扣款，即时到账。
5. 支付成功后自动跳转「卡包 → 未使用」。
6. 注意：支付弹层点击「取消」或遮罩关闭时，未支付的订单会自动取消，不产生扣款。

## 4. 积分 Tab

1. 展示可积分兑换的券（标有「xx 积分」）。
2. 点击「积分兑换」→ 扣减积分 → 券入卡包并跳转「卡包 → 未使用」。
3. 积分不足时提示「积分不足」。

## 5. 兑换 Tab（兑换码）

1. 输入兑换码 → 点击「兑换」。
2. 兑换成功后券自动入卡包，并跳转「卡包 → 未使用」。
3. 无效码 / 非本店码会给出对应中文提示。

## 6. 卡包 Tab

1. 状态筛选：**未使用 / 已使用 / 已过期 / 已退回**。
2. 场景子筛：**全部 / 线上专用 / 到店可用**。
3. 「未使用」按临期排序，剩 7 天内显示红色「剩 N 天」角标。
4. 到店券（含通用券）有「出示券码」按钮 → 打开券码页（二维码 + 券码），到店出示核销。
5. 已使用 / 已过期 / 已退回的券显示对应印章标记，不可再操作。

## 7. 商品页加价购

1. 进入商品详情页，价格卡下方如有「**超值加价购**」区块，展示可换购的券（+¥xx 换购）。
2. 点击「+¥9.9元 立即换购」→ 券挂到当前订单，随单一起结算；按钮变为绿色「已换购 · 点击移除」。
3. 合计金额 = 商品金额 + 加价购券价，在订单结算时一并支付。
4. 点击「点击移除」可随时取消加购。
5. 注意事项：
   - 需先将该商品加入购物车（存在活动订单）才能加购，否则提示引导。
   - 纯到店券不支持线上加购，不会出现在此区块。
   - 未登录点击换购会跳转登录页。
