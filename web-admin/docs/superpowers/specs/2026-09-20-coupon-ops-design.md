# 优惠券运营看板 - 设计

**目标页面**：`src/pages/coupon/index.vue`、发行入口 `coupon/issue`（已有 `couponList` i18n 域）

**背景**：券商列表仅展示模板信息，缺「发放了多少、用了多少、还剩多少」的运营数据，也无法从列表直达发行。

**需求**
1. 券模板卡片新增运营三读：已发放 `issued` / 已核销 `used` / 剩余可用于领取（`totalCount`−`issued` 或接口返回）。
2. 卡片操作行新增「去发行」按钮 → 跳 `coupon/issue`（带当前模板参数）。
3. 顶部 KPI：发放总数 / 核销总数 / 可用券。

**架构**：页面自包含；数据来自既有券列表/详情接口（执行时按真实 API 字段适配，字段缺失则 0/-）。

**数据流**：onShow 拉券模板 → computed 汇总 KPI + 每券三读 → 操作跳转。

**错误处理**：某券无统计字段时显示"−"；跳发行带参失败回退无参 `navigateTo`。

**测试**：build:h5；手机视口截图 券列表带三读+发行按钮。

注：i18n 追加 `couponList` 新键（已发放/已使用/剩余/去发行/发放总数等）。
