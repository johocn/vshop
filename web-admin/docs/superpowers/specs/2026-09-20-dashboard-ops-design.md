# 经营数据看板增强 - 设计

**目标页面**：`src/pages/data/dashboard/index.vue`（区别于工作台 dashboard，已有 `dataDashboard` i18n 域）

**背景**：数据看板现有 KPI/趋势/Top，缺「销售走势（多日维度）」与「库存健康度」两大经营视角。

**需求**
1. 销售趋势：时间 seg（近7天/近30天），按日渲染销售额柱状/折线趋势（前端用同色块 mini 图；数据来自既有聚合接口，执行时适配字段）。
2. TOP 商品：保留现有 Top 榜，补充「销量」冒泡并列展示。
3. 库存健康：新增卡片 — 低库存数 / 缺货数 / 总SKU（数据来自库存预警接口或看板聚合）。

**架构**：页面自包含；时间为 seg 切换重新拉取/前端过滤；图表用纯 CSS/SVG（不引第三方图表库）。

**数据流**：seg → fetch 对应维度聚合 → 渲染趋势条与健康卡。

**错误处理**：趋势接口无数据给空态；金额分转元。

**测试**：build:h5；手机视口截图 近7天趋势+库存健康卡。

注：i18n 追加 `dataDashboard` 新键（近7/近30、低库存/缺货/总SKU、销量）。实现时若聚合接口不存在，用现有接口字段近似或前端过去 mock 兜底渲染预览。
