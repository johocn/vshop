# 收款台账导出增强 - 设计

**目标页面**：`src/pages/settle/ledger/index.vue`（现有 `settleLedger` i18n 域、`onExport` 已有基础 CSV）

**背景**：台账已有全部/已收/待收过滤与基础 CSV 导出，缺按**日期范围**收敛与**按日汇总行**，商户对账不便。

**需求**
1. 日期筛选 seg：今日 / 近7天 / 近30天 / 全部（默认全部）。
2. 列表按日分组标题已存在，增强为组内加一行「当日小计：N 笔 ¥xxxx」。
3. CSV 导出增强：导出当前筛选范围，追加「按日汇总」段（每日 笔数/金额），表头保留。(复用 `downloadCsv`)

**架构**：页面自包含；分组/汇总为前端计算（`computed`）；不新增接口（数据已全量 `fetchSettlementLedgers`）。

**数据流**：rows → dateFilter 过滤 → 按日 groupBy → 每组小计 → 导出时组合明细+汇总。

**错误处理**：空结果导出仅汇总空提示；金额统一分→元 `(n/100).toFixed(2)`。

**测试**：build:h5；手机视口截图 近7天+按日小计；导出产物含汇总段。

注：i18n 按现有 `settleLedger.*` 追加新键（今日/近7/近30、当日小计、按日汇总表头）。
