# 库存预警增强 - 设计

**目标页面**：`src/pages/inventory/stock/index.vue`（及菜单"库存预警"路由所指页面，如为独立页则确认）及相关组价。

**背景**：商户查看库存预警缺批发货场景下批量补货入口，需按仓库/阈值收敛。

**需求**
1. 顶部筛选：仓库下拉（全部/某仓）+ 阈值（现用阈值可配，默认展示低库存）。
2. 列表项展示：SKU/名称、当前仓 onHand、预警阈值、缺货量、状态徽（低库存/缺货）。
3. 批量操作：勾选多个低库存 SKU → 一键「生成采购入库单」，带出选中商品与推荐补货量（阈值−onHand），跳转/生成 stock-doc purchase 草稿。

**架构**：页面内自包含；复用既有 apis（库存/stock-doc purchase 接口）与 `downloadCsv` 无关。批量生成走既有 `createPurchaseDoc` 类接口（由执行时按真实 API 适配）。

**数据流**：onShow 拉取库存/预警清单 → 前端按仓库/阈值过滤 → 勾选集合 → 调 purchase 创建。

**错误处理**：无选中禁操作；生成失败 toast；阈值无显示为 0。

**测试**：`pnpm build:h5`；手机视口截图 过去页（有空数据用假数据兜底渲染预览）。
