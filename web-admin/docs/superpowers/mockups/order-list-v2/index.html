订单列表版式重做 v2 — 三个结构性方案

上一轮三版式的差异字段（showAddress / showDeliveryName / stateColors）全为 true，实际只剩 groupByState 与 stateColumnFirst 两个微调，肉眼难辨。本轮保留三个 key，把差异升级到结构级：信息密度、字段集、分组方式、导航形态都不同。请分别切手机（窄视口）与桌面（宽视口）两态对比。

三方案共用的统一基底（相同部分，不构成差异）

顶部「订单」标题 4 张统计卡：今日 / 待付款 / 待发货 / 待退款 核销码入口 scope 段：渠道单 / 商品单 状态 tab 全枚举 + 5 个折叠组 时间快捷筛选条：今日 / 近7天 / 本月 / 自定义 搜索框 + 配送筛选（快递 / 自提） 同一批 6 条假数据
方案 A

卡片信息流

手机单列大卡片，信息最全、密度最低；桌面走宽表格。不分组，时间倒序平铺。

  • 结构差异 · 密度最低
  • 字段最全：缩略图 + 商品摘要 + 顾客 + 金额 + 时间 + 状态标签
  • 操作组：去发货 / 去核销 / 复制提醒 / 详情
  • 不分组，时间倒序平铺
  • 桌面：宽表格（8 列）
适合：单量小、逐单看详情
 方案 B

状态看板

手机按状态分区的泳道式分区，区内卡片极简；桌面左状态导航 + 右明细表。

  • 结构差异 · 按状态组织
  • 分区头：状态名 + 单数 + 金额小计，可折叠
  • 卡片极简：订单号 / 顾客 / 金额 / 时间 + 1 个主操作，无缩略图
  • 导航形态：桌面左侧含计数的状态导航，高亮当前状态
  • 最利于状态流转
适合：高频按状态流转的运营
 方案 C

高密度清单

手机紧凑两行式清单，一屏可见 10+ 条；桌面紧凑表格，粘性表头 + 斑马纹 + 横向滚动。

  • 结构差异 · 密度最高
  • 手机：无卡片圆角，行间细分隔线，两行一行单
  • 第一行订单号 + 金额；第二行顾客 + 状态色小标签
  • 桌面：行高 36px / 字号 12px / 粘性表头 / 斑马纹
  • 列可横向滚动
适合：单量大、快速扫读

数据为同一批 6 条假订单（202609210001–202609210006，状态覆盖待付款 / 待发货 / 已发货 / 已完成 / 已取消），确保三方案可公平对比。断点统一为 768px。
