订单列表 · 配送信息补齐 — 三个版式方案

统一接入：收货地址行（快递单）、配送方式全名、物流状态标签（待发货橙 / 已发货蓝 / 已完成绿 / 已取消灰）。三方案仅在布局分配上不同，功能一致。切换手机/桌面视口可看响应式两态。

方案 A

卡片 + 表格分离（信息压缩）

手机卡片单列信息流；桌面 8 列表格，地址作收货列子行，配送方式独立一列。触达面广、最贴近现有页面，迁移成本最低。

推荐 · 信息密度平衡
 方案 B

状态优先（运维视角）

状态列/重置卡片顶部，配合更大物流色块 + 配送方式名；桌面加固定筛选 chip 行，按状态快速刷单。适合高频按状态流转的运营场景。

状态流转优先
 方案 C

按状态分组（分区导航）

手机卡片按物流状态分组呈现，每组带小计条；桌面左右分栏：左状态分组计数 + 右明细，地址与方式并入「配送」宽列。信息组织最清晰。

结构化最强
