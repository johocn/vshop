订单列表 · 配送信息补齐 — 三个版式方案

以线上现有效果（e.joho.cn/guanli 订单列表：导航/headbar 统计+核销码/scope/tabs/搜索+筛选/卡片与表格）为基底逐字复刻，仅把「配送信息补齐」三层能力叠加：收货地址行（快递单）、配送方式全名、物流状态标签（待发货橙 / 已发货蓝 / 已完成绿 / 已取消灰）。三方案功能一致，仅在布局分配与信息组织上不同。切手机/桌面视口看响应式两态。

方案 A

现有效果 + 最小改动

完全保留现有结构/列/按钮，仅：配送列「快递」→ 方式全名，收货列加地址子行，手机卡片补方式名 + 新增地址行，状态标签物流着色。对生产影响最小、贴近现有效果，推荐优先落地。

推荐 · 基于现有效果
 方案 B

状态优先（运维视角）

同款基底，但状态列前置到第一列 + 更大物流色块；桌面把「配送（方式+地址）」合并为宽列；顶栏统计改为物流状态计数。适合高频按状态流转的运营。

配送信息更聚焦
 方案 C

按状态分组（分区导航）

同款基底，手机卡片按物流状态分组 + 组内小计；桌面左右分栏：左状态分组计数导航 + 右明细，地址与方式并入「配送」宽列。信息组织最清晰。
