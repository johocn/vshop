# 平台超管 · 租户管理操作说明

适用范围：**平台超管（SuperAdmin）**。入口：`e.joho.cn/guanli` →「租户管理」→ 点击某租户 → 进入「租户详情」。

本章节覆盖三个平台管理功能：**租户改名**、**设置租户默认外网访问域名**、**重置租户管理人密码**。三者均为超管专属，仅在租户详情页可见。

---

## 1. 租户改名

- 位置：租户详情页顶部「租户基础信息」→「店铺名称（租户名）」输入框。
- 操作：修改输入框内的店铺名 → 点击右侧蓝色「保存」按钮。
- 底层：写入 Channel 的 `shopName` 自定义字段（原名 `name` 仅作内部 code，展示名统一用 `shopName`；为空时回退展示为 code）。
- 效果：立即生效，租户列表、租户位格子上展示的新店铺名随之更新。

## 2. 设置租户默认外网访问域名

- 位置：同一张「租户基础信息」卡，第二行「默认外网访问域名」输入框。
- 操作：输入域名（**不要带 `http(s)://` 前缀**，如 `store.example.com`）→ 点击「保存」。
- 底层：写入 Channel 新增的 `domain` 自定义字段，前端据此域名回源。
- 提示：
  - 传入值会去除空白后保存；若不带协议前缀，前端会按 `https://` 补全回源。
  - 空值保存不会清空已有域名（避免误清）；如需清空请在平台层处理。
  - 该字段未来供多城市 SEO / 独立域名分流使用。

### 2.1 默认域名的自动生成

- 默认外网地址规则：**主域 + 路径后缀** `www.youshop.cn/{code}`（不使用子域，因无法解析）。例如 code 为 `t24` 的租户默认地址为 `www.youshop.cn/t24`。
- **新建租户自动带上**：通过「＋新建租户」创建时，后端会自动写入该默认 `domain`，无需手工填写。
- 默认主域 `www.youshop.cn` 可在后端配置 `defaultPublicDomain`（插件 `tenant` 配置项）设定，支持 `DEFAULT_PUBLIC_DOMAIN` 环境变量覆盖。
- **存量租户**：平台已对全部现有租户批量补填默认 `domain`（官方店占用 `official-XX`、普通商店占用 `t{n}`、演示店占用自身 code）。仅 Vendure 系统保留渠道 `__default_channel__` 保持为空。

## 3. 重置租户管理人密码

- 位置：详情页「管理员」Tab → 管理员列表每一行右侧「重置密码」链接。
- 操作：点击「重置密码」→ 二次确认弹窗 → 确认。
- 效果：将该管理员的登录密码重置为固定默认口令 **`you123123`**，并清除其"首登强制改密"标志，可直接用该口令登录。
- 前提：该管理员必须已在此租户的管理员列表内（若某租户暂无管理员，会显示「暂无管理员」，此时需先「＋添加管理员」）。

---

## 权限与接口

| 功能 | 权限 | Admin API |
|------|------|-----------|
| 租户改名 | SuperAdmin | `updateTenant(id, { name })` |
| 设置域名 | SuperAdmin | `updateTenant(id, { domain })` |
| 重置管理人密码 | SuperAdmin | `resetTenantAdministratorPassword(memberId)` |

> 三个接口均带 `@Allow(Permission.SuperAdmin)`，非超管调用会被拒绝（FORBIDDEN）。
