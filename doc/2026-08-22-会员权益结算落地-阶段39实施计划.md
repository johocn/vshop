**设计（复用已有 `tierEligibleCondition` + `tierDiscountAction`）：**

等级折扣按 `minLevel` 门槛拆分两条 Promotion，避免单 Promotion 误伤低等级新客：
- **白银及以上**：`minLevel: 2`，用 `specialDiscountRate`（若全局配置金的档位则为金及以上折让）。
- 说明：`specialDiscountRate` 是**单档位千分比**（非递增累计）。阶段30 默认档位表中金卡 `specialDiscountRate=950`（95折）、白金 900（9折）、钻石 850（8.5折），普通/银卡 1000（无折扣）。因此只需一条「金卡及以上 95 折」Promotion（`minLevel: 3`）即可让金/白/钻都获得 ≥95 折，银卡无专属折扣（由免运费/积分倍率承担权益）。

- [ ] **Step 1: sources.ts 追加 `TIER_DISCOUNT_PROMOTIONS`**

在 `PROMOTIONS` 数组（`sources.ts` 约 L875）末尾追加两条（避免与既有满减/券冲突，用独立 `PromotionSource`）：

```typescript
// ===== 会员等级专属折扣（阶段39，weekend 复用 tier_eligible/tier_discount）=====
export const TIER_DISCOUNT_PROMOTIONS: PromotionSource[] = [
    {
        name: '金卡及以上专属95折',
        couponCode: '', // 无券码，结算自动按等级适用
        channel: 'default',
        conditions: [{ code: 'tier_eligible', arguments: [{ name: 'minLevel', value: '3' }] }],
        actions: [{ code: 'tier_discount', arguments: [] }],
        customFields: { stackable: true, stackableGroup: null, maxStackableWith: null },
    },
    {
        name: '银卡及以上专属98折',
        couponCode: '',
        channel: 'default',
        conditions: [{ code: 'tier_eligible', arguments: [{ name: 'minLevel', value: '2' }] }],
        actions: [{ code: 'tier_discount', arguments: [] }],
        customFields: { stackable: true, stackableGroup: null, maxStackableWith: null },
    },
];
```

> 说明：`tier_discount` 动作从 state（`tierEligibleCondition` 写入）读 `specialDiscountRate` 折让，两条 Promotion 的差距在 `minLevel` 门槛。若无需银卡折扣可只留金卡条。

## 依赖与风险

- 等级折扣 `specialDiscountRate` 为**单档位非递增**，金卡条 `minLevel:3` 使白金/钻石复用金卡折扣；若需区别档位折扣，需确认各档 `specialDiscountRate` 数值（阶段30 默认 金950/白900/钻850）。
- 现有 `couponDiscountYuan`（checkout.vue）把所有 `discounts` 累加为「优惠券」，需精确定位 coupon 来源，避免等级折扣被误计入券。
- 若 dev 库已 seed 过（非首次启动），新增 Promotion 需重置种子或手动 Admin `createPromotion` 等价录入；e2e 脚本可垫高成长值触发。
