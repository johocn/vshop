# Youshop 前端使用手册

## 1. 环境准备

### 1.1 系统要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Node.js | >= 20.x | LTS 版本 |
| npm | >= 9 | 包管理器 |

### 1.2 安装依赖

```bash
cd e:/code/youshop
npm install
```

---

## 2. 启动与运行

### 2.1 H5 开发

```bash
npm run dev:h5
```

启动后访问 http://localhost:5173（端口可能自动递增）。

### 2.2 微信小程序开发

```bash
npm run dev:mp-weixin
```

编译输出到 `dist/dev/mp-weixin/` 目录，使用**微信开发者工具**打开该目录。

### 2.3 构建生产版本

```bash
# H5 生产构建
npm run build:h5
# 输出到 dist/build/h5/

# 小程序生产构建
npm run build:mp-weixin
# 输出到 dist/build/mp-weixin/
```

## 5. 微信调试

### 5.1 微信开发者工具

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入项目：选择 `dist/dev/mp-weixin/` 目录
3. 在"详情" → "本地设置"中启用"不校验合法域名"（开发环境）

### 5.2 H5 微信浏览器调试

1. 启动 H5 开发服务器
2. 在微信开发者工具中选择"公众号网页"模式
3. 输入 H5 开发地址（如 http://localhost:5173）
4. **注意**：本地开发无法使用微信 OAuth，需要配置内网穿透或在测试环境验证

### 5.3 JS-SDK 调试

在 `utils/wechat.ts` 中临时设置 `debug: true`：

```typescript
wx.config({
    debug: true,  // 开启调试，页面会弹窗显示配置结果
    appId: sig.appId,
    // ...
});
```

也可使用微信开发者工具的"微信 JS-SDK 调试"功能。

## 6. 登录流程说明

### 6.1 三种登录方式

| 方式 | 触发条件 | 流程 |
|------|---------|------|
| 微信 H5 登录 | 微信浏览器 + AppID 已配置 | OAuth 授权 → 获取 code → authenticate |
| 手机验证码登录 | 点击"手机号登录" | 发送验证码 → 输入验证码 → authenticate |
| 账号密码登录 | 点击"账号密码登录" | 输入用户名密码 → login |

### 6.2 H5 微信浏览器自动登录

```
用户打开页面
    │
    ├─ 已登录（authStore.token 有值）→ 正常使用
    │
    └─ 未登录 + 微信浏览器 + AppID 已配置
        │
        └─→ 自动跳转微信 snsapi_base 授权页
            │
            └─→ 微信重定向回页面（带 code + state=wechat_base）
                │
                └─→ onMounted 检测 → handleWechatH5Callback → authenticate
                    │
                    └─→ 登录成功 → 跳转首页
```

### 6.3 手动微信登录

点击"微信登录"按钮触发 `snsapi_userinfo` 授权，弹窗询问用户是否授权获取昵称头像。

## 7. 分享功能

### 7.1 H5 分享

在微信浏览器中，页面可被分享到好友或朋友圈。

使用方式：

```typescript
// 在页面 setup 中调用
import { useShare } from '@/composables/useShare';

useShare({
    title: '分享标题',
    path: '/pages/home/index',
    imageUrl: 'https://...',
});

// 商品分享
import { useProductShare } from '@/composables/useShare';
useProductShare('商品名称', 'product-slug', 'https://image.url');
```

### 7.2 小程序分享

小程序使用原生分享 API，`useShare` 内部自动处理：
- `onShareAppMessage` — 分享给好友
- `onShareTimeline` — 分享到朋友圈

### 7.3 邀请码自动携带

分享链接自动拼接邀请码参数：

```
原始链接: https://shop.com/#/pkg-product/pages/detail?slug=xxx
分享链接: https://shop.com/#/pkg-product/pages/detail?slug=xxx&ref=USER_CODE
```

好友打开链接 → App.vue 捕获 `ref` → 存入 authStore.inviteCode。

## 8. 发布流程

### 8.1 H5 发布

```bash
# 构建
npm run build:h5

# 部署 dist/build/h5/ 目录到 Web 服务器
# 配置 Nginx 反向代理到后端 API
```

Nginx 配置示例：

```nginx
server {
    listen 443 ssl;
    server_name shop.example.com;
    root /var/www/youshop/dist/build/h5;
    index index.html;

    location /shop-api {
        proxy_pass http://localhost:3000;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### 8.2 小程序发布

```bash
# 构建
npm run build:mp-weixin

# 用微信开发者工具打开 dist/build/mp-weixin/
# 点击"上传" → 填写版本号 → 提交审核
```

### 8.3 微信平台配置

发布前需在微信公众平台配置：

| 配置项 | 位置 | 值 |
|--------|------|-----|
| 网页授权域名 | 公众号 → 开发 → 接口权限 → 网页授权 | shop.example.com |
| JS 安全域名 | 公众号 → 设置 → 功能设置 → JS接口安全域名 | shop.example.com |
| request 合法域名 | 小程序 → 开发 → 开发管理 → 服务器域名 | https://api.example.com |
| 业务域名 | 小程序 → 开发 → 开发管理 → 业务域名 | shop.example.com |

## 9. 微信小程序收款配置

小程序微信支付（JSAPI）链路已内置：下单 → `addPaymentToOrder` 返回签名参数 →
`wx.requestPayment` 拉起收银台 → 微信异步回调 `/wechatpay/notify` → 订单自动结算 →
pay-result 页轮询确认真实状态。收款前提是完成以下配置。

### 9.1 微信商户平台（pay.weixin.qq.com）

1. 注册商户号，完成资质审核，记录 **mchId**。
2. 「产品中心 → AppID 账号管理」：绑定小程序的 **AppID**。
3. 「账户中心 → API 安全」：
   - 设置 **APIv3 密钥**（apiKey，32 位）。
   - 申请 **API 证书**：下载商户私钥 `apiclient_key.pem`，记录**证书序列号**（serialNo）。
   - 下载**微信平台公钥**（PEM 文件内容，publicKey）。

### 9.2 后台录入凭证（Vendure Admin）—— 分端三个支付方法

「Settings → Payment Methods」按端创建三个支付方法（handler 均为 `wechatpay`）：

| code | 用途 | 商户 | appId |
|------|------|------|-------|
| `wechatpay` | 小程序 JSAPI | 商户A（yourbao） | yourbao 小程序 AppID |
| `wechatpay-yourbao-h5` | yourbao 公众号 JSAPI | 商户A（yourbao） | yourbao 公众号 AppID |
| `wechatpay-youshop-jsapi` | youshop 公众号 JSAPI | 商户B（youshop） | youshop 公众号 AppID |

每个方法填写：appId / mchId / apiKey（APIv3 密钥）/ privateKey（apiclient_key.pem 全文）/
publicKey（微信平台公钥全文）/ serialNo（证书序列号）/ tradeType=`JSAPI`，
以及新增的 **notifyUrl**（见 9.3，按各自域名填写）。

多租户：渠道 `payConfig.wechatpayJson` 同套凭证 + `notifyUrl`，优先级高于 PaymentMethod args。

### 9.3 回调地址

实际路由为 `{域名}/shop-api/wechatpay/notify`（nginx 将 `/shop-api` 代理到 vendure）：

| 支付方法 | notifyUrl |
|----------|-----------|
| wechatpay | `https://www.yourbao.cn/shop-api/wechatpay/notify` |
| wechatpay-yourbao-h5 | `https://www.yourbao.cn/shop-api/wechatpay/notify` |
| wechatpay-youshop-jsapi | `https://www.youshop.cn/shop-api/wechatpay/notify` |

回调地址四级回落：渠道 payConfig > PaymentMethod args.notifyUrl > 全局 env `WECHATPAY_NOTIFY_URL`。
必须公网 HTTPS 可访问，微信支付成功后主动 POST 该地址，服务端验签后自动结算订单。

### 9.4 小程序端域名

微信公众平台（小程序后台）→「开发管理 → 开发设置 → 服务器域名」：
request 合法域名加入 `https://www.yourbao.cn`。

### 9.5 生产开关

生产环境 `WechatpayPlugin.init({ devBypass: false })`。
devBypass=true 时仅返回模拟支付页，**不会真实收款**。

### 9.6 测试流程

1. 后台下一笔 0.01 元测试单，小程序真实支付。
2. 预期：收银台拉起 → 支付成功 → pay-result 页数秒内变「✅ 支付成功」。
3. 取消支付：pay-result 保持「⏳ 等待支付确认」+「继续支付」按钮；订单详情可重新支付。
4. 超时兜底：回调未及时到达时，pay-result 显示「支付确认中，如已扣款稍后自动到账」，
   不误判为失败。

### 9.7 分端分支付方案（已内置）

两端均归属默认渠道「优商铺」，数据不分家；微信收款按「端/域名」自动路由：

| 端 | 支付方法 | 商户 | 回调验签凭证 |
|----|----------|------|--------------|
| 小程序 | `wechatpay` | 商户A | Host=www.yourbao.cn → wechatpay |
| H5 yourbao 域 | `wechatpay-yourbao-h5` | 商户A | Host=www.yourbao.cn → wechatpay |
| H5 youshop 域 | `wechatpay-youshop-jsapi` | 商户B | Host=www.youshop.cn → wechatpay-youshop-jsapi |

- **前端路由**（`usePayment.resolveWechatMethodCode`）：小程序固定 `wechatpay`；
  H5 按域名（含 `yourbao` → yourbao-h5，否则 youshop-jsapi）。结算页只显示当前端的方法。
- **回调验签**（插件 `callbackMethodMap`）：微信 v3 回调报文用商户 APIv3 密钥加密、
  解密前拿不到单号，故按回调 Host 路由凭证；未命中回退渠道 override + `wechatpay`。
- **服务器 env**（`packages/dev-server/.env`，已配置）：

```
WECHATPAY_EXTRA_HANDLER_CODES=wechatpay-yourbao-h5,wechatpay-youshop-jsapi
WECHATPAY_CALLBACK_METHOD_MAP={"www.yourbao.cn":"wechatpay","www.youshop.cn":"wechatpay-youshop-jsapi"}
```

- **充值/券支付**：当前固定走 `wechatpay`（商户A），仅小程序场景可用；
  H5 端充值随 MWEB 轮次一并支持（ BarePaymentInput.methodCode 已预留）。
- **微信外浏览器 H5 支付（MWEB）**：后续轮次实现（handler 已支持 tradeType=H5，
  待配置商户 H5 支付产品与前端跳转）。

### 9.8 公众号 JSAPI 收款前提

- yourbao / youshop 各需一个**已认证服务号**，且在商户平台完成 AppID 绑定与
  「JSAPI 支付」产品开通，支付目录配置对应 H5 域名。
- 公众号网页需 JS-SDK 签名时复用 zhao-sso 插件 `POST /v1/auth/jssdk-signature`
  （access_token / jsapi_ticket 已做缓存）。
