# 余额钱包 C 端 设计

> 日期：2026-08-21
> 工程：`vshop`（Vendure C 端商城，UniApp · H5 + 微信小程序）
> 上游依赖：阶段34「支付网关 + 会员在线充值」后端已就绪（recharge-card-plugin shop API）

## 1. 目标

打通会员余额钱包的 C 端闭环：在线充值（微信支付）+ 真实余额流水展示。覆盖 **H5 + 微信小程序** 两端（APP 留待后续）。

## 2. 现状

- `src/pkg-user/pages/recharge.vue`：仅卡密充值 + 当前余额展示，无在线充值入口。
- `src/pkg-user/pages/balance-history.vue`：仅列充值卡 `myRechargeHistory`（面和/日期），未接真实余额流水。
- 前端已有可直接复用设施：`composables/usePayment.ts`（wechatpay 的 mp/h5/app 分支）、`utils/platform.ts` 的 `wxRequestPayment` / `redirectPayment`、`pages/webview/index.vue`（支付 webview）。
- 后端 shop API 已备齐（阶段34）：`myRechargeBalance`、`myBalanceTransactions(options)`、`myRechargeOrders`、`createRechargeOrder(amount, remark)`、`createWechatRechargePayment(rechargeOrderId, tradeType, openid)`、`cancelRechargeOrder(id)`。

## 3. 交互设计

### 3.1 充值页（`recharge.vue`，同页双入口）

顶部：余额卡（余额分→元展示，保留）

**「在线充值」区块**
- 金额快捷档位：¥50 / ¥100 / ¥200 / ¥500 + 自定义金额输入
- 点「微信充值」：
  - 小程序：`createRechargeOrder(amount)` → `createWechatRechargePayment(id, tradeType='JSAPI', openid)` → `usePayment` `wxRequestPayment` 调起支付
  - H5：`createRechargeOrder(amount)` → `createWechatRechargePayment(id, tradeType='H5')` → `redirectPayment(payUrl)`（生产 h5_url，dev 态 dev-pay 页）
- 支付结果返回后：刷新余额 + 提示 + 跳转到余额明细

**「卡密充值」区块**（保留现有）

### 3.2 余额明细页（`balance-history.vue` 重构）

接 `myBalanceTransactions(options)`，按 `type` 映射文案与正负色：

| type | 文案 | 金额色 |
|------|------|:---:|
| recharge | 充值 | +绿色 |
| consumption | 消费 | - |
| refund | 退款 | +绿色 |
| adjustment | 调账 | ± |

支持触底分页 + 下拉刷新。

### 3.3 入口文案

`pkg-user/pages/profile.vue`：`充值卡` → `我的钱包`。

## 5. 安全 / 边界

- 复用 `usePayment` 现成的 wechatpay 分支，不发散。
- 支付入账由后端回调驱动（阶段34已做幂等），前端返回后仅刷新余额，不做对账轮询。
- 未登录走既有 `useAuthGuard` 跳登录。
- 明确不做：APP 端、多档位联动优惠（本期纯面额）、支付成功主动轮询。
