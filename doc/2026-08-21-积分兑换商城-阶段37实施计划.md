# 积分兑换商城（阶段37）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 C 端「会员权益整合中心」之上新增 **积分兑换商城**：顾客用积分兑换优惠券/红包式固定金额券，形成「积分 → 权益」闭环。

**Architecture:** 后端在 **coupon-plugin** 内扩展——给 `CouponTemplate` 加 `pointsPrice`（0=不可积分兑换），新增 Shop query `pointsMallTemplates` 与 mutation `exchangeCouponWithPoints`；兑换时注入 `MemberLevelService.spendPoints` 扣积分（记 SPEND 流水）、复用券插件发券逻辑（库存/限购/原子防超发）。C 端新增 `points-mall.vue` 页 + API 封装 + 入口。

**Tech Stack:** Vendure plugin（NestJS、TypeORM）、GraphQL、Vue 3 `<script setup>`、uni-app、usePagination。

**关键复用：**
- 跨插件注入 `MemberLevelService`（Vendure 全局可注入，参照 operations-plugin 注入 CouponService 先例）
- 券发放：`coupon-service` 的 `atomicIncrementClaimed`（原子防超发）+ `createUserCoupon`（唯一码+库存）
- 扣积分：`member-level-service.spendPoints(ctx, customerId, amount, orderId, remark)`（原子扣减+SPEND 流水+不足抛错）

**风险缓解：** 运行时 DB 为空迁移但插件实体可建（recharge-card/member-level 均已运行）→ 采用 `synchronize:true`（sqlite 分支）运行，新增列自动同步；置 `issuedBy` 扩 `EXCHANGE`，不破坏既有券。

```ts
async pointsMallTemplates(ctx: RequestContext): Promise<CouponTemplate[]> {
    const repo = this.connection.getRepository(ctx, CouponTemplate);
    const now = new Date();
    return repo.createQueryBuilder('tpl')
        .innerJoin('tpl.channels', 'channel', 'channel.id = :channelId', { channelId: ctx.channelId })
        .where('tpl.enabled = :enabled', { enabled: true })
        .andWhere('tpl.pointsPrice > 0')
        .andWhere('(tpl.startsAt IS NULL OR tpl.startsAt <= :now)', { now })
        .andWhere('(tpl.endsAt IS NULL OR tpl.endsAt >= :now)', { now })
        .orderBy('tpl.pointsPrice', 'ASC')
        .getMany();
}

async exchangeWithPoints(ctx: RequestContext, templateId: ID): Promise<{ coupon: CustomerCoupon; spentPoints: number }> {
    const customerId = await this.currentCustomerId(ctx);
    if (!customerId) throw new UserInputError('No customer for the current user');
    const tpl = await this.findOneTemplate(ctx, templateId);
    if (!tpl) throw new UserInputError(`CouponTemplate ${templateId} not found`);
    if (tpl.pointsPrice <= 0) throw new UserInputError('This coupon is not exchangeable with points');
    const now = new Date();
    if (!tpl.enabled) throw new UserInputError('Coupon template is disabled');
    if (tpl.startsAt && now < tpl.startsAt) throw new UserInputError('Not yet started');
    if (tpl.endsAt && now > tpl.endsAt) throw new UserInputError('Coupon redeemed');
    if (tpl.perUserLimit > 0) {
        const owned = await this.countHeld(customerId, tpl.id);
        if (owned >= tpl.perUserLimit) throw new UserInputError('Per-user redemption limit reached');
    }
    // 扣积分（原子+SPEND流水；不足抛 Insufficient）
    await this.memberLevelService.spendPoints(ctx, customerId, tpl.pointsPrice, null, `积分兑换优惠券:${tpl.name}`);
    // 原子扣发行余量（防超发）
    const ok = await this.atomicIncrementClaimed(ctx, tpl.id, tpl);
    if (!ok) throw new UserInputError('Coupon sold out');
    const coupon = await this.createUserCoupon(ctx, customerId, tpl, 'EXCHANGE');
    return { coupon, spentPoints: tpl.pointsPrice };
}
```
