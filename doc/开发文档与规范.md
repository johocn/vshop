# VShop 前端开发文档与规范

## 1. 技术架构

### 1.1 框架概述

本项目基于 **uni-app Vue 3** 构建，使用 Vue 3 Composition API（`<script setup>`）开发，支持一套代码多端编译：

- **H5** — Web 浏览器（含微信内置浏览器）
- **微信小程序** — 微信生态小程序
- **App** — 原生移动应用（可选）

构建工具：**Vite 5**，CSS 预处理器：**SCSS**，状态管理：**Pinia**。

### 1.2 条件编译

uni-app 通过特殊注释实现多端条件编译，编译时自动剔除不匹配的分支：

```html
<!-- #ifdef H5 -->
<div>仅在 H5 环境显示</div>
<!-- #endif -->

<!-- #ifdef MP-WEIXIN -->
<button open-type="share">小程序分享</button>
<!-- #endif -->

<!-- #ifndef H5 -->
<div>非 H5 环境显示</div>
<!-- #endif -->
```

JS 中同理：

```typescript
// #ifdef H5
console.log('H5 only');
// #endif

// #ifdef MP-WEIXIN
console.log('小程序 only');
// #endif
```

### 2.2 分包策略

`pages.json` 中配置分包加载，减少主包体积：

| 分包 | 路径 | 页面数 | 预加载规则 |
|------|------|--------|-----------|
| pkg-product | 商品相关 | 2 | 首页进入时预加载 |
| pkg-order | 订单相关 | 5 | 购物车页进入时预加载 |
| pkg-after-sale | 售后 | 3 | - |
| pkg-promotion | 营销活动 | 3 | 首页进入时预加载 |
| pkg-user | 用户中心 | 6 | - |

### 2.3 SCSS 主题系统

全局 SCSS 变量定义在 `src/uni.scss` 中，由 uni-app **自动注入**到每个组件，无需手动 import：

```scss
// uni.scss 中定义的变量可在任何组件中直接使用
$brand-color: #ff6600;
$text-color: #333;
$border-color: #e5e5e5;
$radius-md: 12rpx;
```

**注意**：不要在 `vite.config.ts` 中配置 `additionalData`，uni-app 已自动处理注入。

## 3. 页面开发规范

### 3.1 页面文件结构

每个页面文件包含三部分：

```vue
<template>
  <view class="page-container">
    <!-- 页面内容 -->
  </view>
</template>

<script setup lang="ts">
import { ref, computed, onMounted } from 'vue';
import { onLoad } from '@dcloudio/uni-app';

// 响应式数据
const data = ref<any>(null);

// 页面参数
onLoad((query: any) => {
    const id = query?.id;
});

// 生命周期
onMounted(() => {
    // 初始化逻辑
});
</script>

<style lang="scss" scoped>
.page-container {
    min-height: 100vh;
    padding: 20rpx;
}
</style>
```

### 3.2 生命周期

| 钩子 | 来源 | 用途 |
|------|------|------|
| `onLoad(query)` | @dcloudio/uni-app | 页面加载，接收路由参数 |
| `onMounted` | vue | 组件挂载完成 |
| `onShow` | @dcloudio/uni-app | 页面显示（含从后台返回） |
| `onPullDownRefresh` | @dcloudio/uni-app | 下拉刷新（需在 pages.json 中启用） |
| `onReachBottom` | @dcloudio/uni-app | 触底加载 |

### 3.3 路由导航

```typescript
// 普通跳转
uni.navigateTo({ url: '/pkg-product/pages/detail?slug=' + slug });

// Tab 页切换（只能跳 tabBar 页面）
uni.switchTab({ url: '/pages/home/index' });

// 替换当前页
uni.redirectTo({ url: '/pages/login/index' });

// 返回上一页
uni.navigateBack();
```

## 4. 状态管理

### 4.1 Pinia Store 模式

使用 Composition API 风格定义 Store：

```typescript
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';

export const useXxxStore = defineStore('xxx', () => {
    const data = ref<any>(null);
    const count = computed(() => data.value?.count || 0);

    function setData(newData: any) { data.value = newData; }

    return { data, count, setData };
});
```

### 4.2 现有 Store

| Store | 文件 | 用途 | 持久化 |
|-------|------|------|--------|
| authStore | stores/auth.ts | token, userId, userInfo, inviteCode | localStorage |
| cartStore | stores/cart.ts | 购物车 order 数据 | - |
| tenantStore | stores/tenant.ts | 租户 token, 功能开关 | localStorage |
| uiStore | stores/ui.ts | loading, toast 状态 | - |

### 4.3 数据持久化

使用 `uni.setStorageSync` / `uni.getStorageSync` 实现本地持久化：

```typescript
// 存储
uni.setStorageSync('auth_token', token);

// 读取
const token = uni.getStorageSync('auth_token') || '';

// 删除
uni.removeStorageSync('auth_token');
```

## 5. API 层

### 5.1 GraphQL Client 封装

`api/client.ts` 提供统一的 GraphQL 客户端：

```typescript
import { getGraphQLClient, deduped } from '../client';

// 标准请求
const client = getGraphQLClient();
const data = await client.request(query, variables);

// 防重复请求
const data = await deduped('product:' + slug, async () => {
    return client.request(query, { slug });
});
```

### 5.2 认证请求

`api/mutations/auth.ts` 使用 `uni.request` 直接请求，从 response header 提取 token：

```typescript
function authRequest(query, variables) {
    return new Promise((resolve, reject) => {
        uni.request({
            url: API_URL,
            method: 'POST',
            header: getAuthHeaders(),
            data: { query, variables },
            success: (res) => {
                const authToken = res.header['vendure-auth-token'] || '';
                resolve({ data: res.data, authToken });
            },
        });
    });
}
```

**关键**：Vendure 的认证 Token 通过 `vendure-auth-token` response header 返回，不在 GraphQL body 中。

### 5.3 文件组织

| 目录 | 内容 | 示例 |
|------|------|------|
| mutations/ | 写操作 | auth.ts, cart.ts, checkout.ts |
| queries/ | 读操作 | product.ts, order.ts, user.ts, wechat.ts |
| fragments.ts | 共享 Fragment | ProductFragment, OrderFragment |

## 6. 微信生态集成

### 6.1 H5 双模式登录

```
微信浏览器打开页面
    │
    ├─ 未登录 + 微信浏览器 + appId 已配置
    │   └─→ 自动触发 snsapi_base 静默登录（无弹窗）
    │
    └─ 用户点击"微信登录"按钮
        └─→ 触发 snsapi_userinfo 完整授权（弹窗）
```

- **snsapi_base**：静默授权，仅获取 openid，无用户感知
- **snsapi_userinfo**：弹窗授权，可获取用户昵称头像

### 6.2 JS-SDK 分享

```typescript
// utils/wechat.ts 封装
ensureWxReady()  // 加载 JS-SDK → 获取签名 → wx.config → wx.ready

// composables/useH5Share.ts
useH5Share({ title, desc, link, imageUrl })  // 设置分享数据
useH5ProductShare(name, slug, imageUrl)      // 商品分享快捷方法
```

**签名 URL 规则**：必须使用 `location.href.split('#')[0]`，不含 hash 部分。

### 6.3 平台自适应分享

`useShare.ts` 自动根据平台选择分享方式：

| 平台 | 方式 |
|------|------|
| 微信小程序 | `onShareAppMessage` + `onShareTimeline` |
| H5 微信浏览器 | `wx.updateAppMessageShareData` + `wx.updateTimelineShareData` |
| H5 非微信浏览器 | 无分享功能 |

### 6.4 邀请码机制

1. **捕获**：`App.vue` 的 `onLaunch` 中从 URL 参数 `ref` 提取邀请码
2. **存储**：`authStore.setInviteCode(code)` → localStorage
3. **使用**：分享链接自动拼接 `?ref={inviteCode}`

## 8. 编码规范

### 8.1 Vue 3 Composition API

- 使用 `<script setup lang="ts">` 语法
- 响应式数据用 `ref` / `reactive`
- 计算属性用 `computed`
- 避免使用 Options API

### 8.2 TypeScript

- 定义接口类型（`interface`），避免 `any`
- API 返回值定义明确类型
- Store 中 `userInfo` 等复杂类型可暂用 `any`

### 8.3 SCSS 变量

直接使用 `uni.scss` 中定义的全局变量，无需 import：

```scss
.button {
    color: $brand-color;         // 直接使用全局变量
    border-radius: $radius-md;
}
```

### 8.4 尺寸单位

- 使用 `rpx`（响应式像素），自动适配不同屏幕
- `750rpx` = 屏幕宽度

### 8.5 命名约定

| 类型 | 规范 | 示例 |
|------|------|------|
| 页面文件 | kebab-case 目录 | `pages/login/index.vue` |
| 组件 | PascalCase 文件 | `ProductCard.vue` |
| Store | useXxxStore | `useAuthStore` |
| Composable | useXxx | `useH5Share` |
| CSS Class | BEM 风格 | `login-page__input` |
